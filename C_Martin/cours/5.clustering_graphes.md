# Clustering sur Graph
## Clustering spectral
Ne s'appuie pas sur des clusters rond ... comme Kmeans, mais sur la proximité avec les voisins  
$\to$ 2 points sont dans le même cluster s'ils sont dans une zone dense = chemin de points proches  
- Graphe : On fabrique une matrice d'affinité (proximité du points avec les autres)  
- Spectre : k 1er vecteurs propres donne nouvelle représentation de dim k
- Partition : appliquer un Kmeans sur le nouvel espace

**Etape 1: Graphe de similarité**  
on peut s'appuyer sur plusieurs méthodes : 
- $\epsilon$-voisinage, 
- k plusp roches voisins 
- graphe complet pondéré par un noyau gaussien : $w_{ij} = exp(-\frac{||x_i-x_j||^2}{2 \sigma ^2})$
